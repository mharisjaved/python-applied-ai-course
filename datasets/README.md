# Course datasets

Small, **synthetic** datasets shared by the AI weeks (9–12) and some Python lessons. No real people or
organisations are described. Numeric datasets are generated by `scripts/make_datasets.py` (seeded, so the files
are identical every time it runs).

From a lesson notebook (`weeks/week-XX/day-YY-…/demo.ipynb`) the folder is three levels up:

```python
from pathlib import Path
DATA_DIR = Path("../../../datasets")
```

| File | Rows | Used in | What it is |
|------|------|---------|------------|
| `students_raw.csv` | 304 | D42, D45 | Student study habits and results **with deliberate quality problems** |
| `students.csv` | 298 | D46–D50, projects 06/07 | Cleaned version of the raw file (exactly the Day 45 recipe) |
| `apartments.csv` | 250 | D47, Project 07 | Apartment features and prices (regression) |
| `expenses.csv` | 148 | D36–D37, D44 | Personal expenses, Sep–Nov 2026 |
| `reviews.csv` | 40 | D51–D55, Project 08 | Short product reviews (hand-written) |
| `campus_faq.md` | – | Project 09 option C | FAQ of a fictional learning centre (knowledge base for a Q&A assistant) |

scikit-learn's bundled datasets (`load_iris`, `load_wine`, `load_breast_cancer`) need no download and may also be used.

## students_raw.csv / students.csv

| Column | Type | Meaning |
|--------|------|---------|
| `student_id` | text | `S001`… |
| `program` | category | `science`, `commerce`, `arts` |
| `study_hours` | number | self-study hours per week |
| `attendance_pct` | number | % of classes attended |
| `sleep_hours` | number | average hours of sleep per night |
| `previous_score` | number | score in the previous term (0–100) |
| `assignments_done` | number | assignments submitted out of 10 |
| `has_job` | category | `yes` / `no` (part-time job) |
| `final_score` | number | final exam score (0–100), **regression target** |
| `passed` | 0/1 | 1 if `final_score >= 50`, **classification target** (71% pass) |

Problems planted in `students_raw.csv`: 8 missing `study_hours`, 6 missing `sleep_hours`, inconsistent text in
`program` and `has_job` (`"Yes"`, `" no"`, `"ARTS"`…), 4 exact duplicate rows, one `attendance_pct` of 150, and
one negative `study_hours`.

**Day 45 cleaning recipe** (produces `students.csv` exactly):
1. `drop_duplicates()`
2. `.str.strip().str.lower()` on `program` and `has_job`
3. keep rows with `attendance_pct <= 100` and `study_hours` not negative
4. fill missing `study_hours` and `sleep_hours` with the column median

⚠️ Leakage lesson (D49): `final_score` must not be a feature when predicting `passed`, because it defines the label.

## apartments.csv

`apartment_id`, `area_sqm`, `bedrooms`, `age_years`, `distance_km` (to city centre), `floor`,
`has_parking` (0/1), `price_k` (price in thousands of a generic currency, **target**).

## expenses.csv

`date` (YYYY-MM-DD), `category` (food, transport, rent, utilities, entertainment, health, shopping),
`description`, `amount`, `payment_method` (card, cash, transfer). Rent and utilities are paid on the 1st of each month.

## reviews.csv

`review_id`, `product` (5 products), `rating` (1–5), `review_text`. Includes realistic edge cases for LLM lessons:
a one-word review (R05), mixed sentiment (R31), sarcasm whose 5-star rating contradicts the text (R36), a review
about delivery rather than the product (R27, R39), and one containing (fictional) personal contact details (R33)
for the privacy discussion.
