# Assessments

| What | When | File |
|------|------|------|
| Weekly checkpoint 1–7, 9–11 (15–20 min) | Last session of each week; on project days it opens the session (D15, D20, D35, D50, D55), and Checkpoint 9 opens Day 46 | `weekly/week-NN-checkpoint.md` |
| Python readiness assessment (45–60 min) | Day 40, replaces the Week 8 checkpoint | [final/python-readiness.md](final/python-readiness.md) |
| Final AI assessment (30–45 min) | Day 60, replaces the Week 12 checkpoint | [final/ai-final-assessment.md](final/ai-final-assessment.md) |
| Projects (graded with the shared rubric) | Days 15, 20, 30, 35, 38–40, 45, 50, 55, 56–60 | [../projects/README.md](../projects/README.md) |

Each checkpoint file has the questions, then a horizontal rule and a pointer to its **answer key**, which lives in
`answer-keys/<same file name>` (instructor only, not published). Copy only the questions part for students (paper,
a shared doc, or a quiz form).

**How to use the results:** checkpoints are low-stakes retrieval practice, not exams. Note the weakest question
in `PROGRESS.md` ("Reviewed / needs reinforcement") and spend 5 minutes of the next warm-up on it.

Suggested weighting if a final grade is required: projects 01–04 and 06–08 = 40%, Python capstone = 20%,
AI capstone = 25%, checkpoints + assessments = 15%.
